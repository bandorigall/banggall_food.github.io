================================================================
맛집 (banggall_food.github.io) — 모듈 개요 (기술 명세)
================================================================

0. 목적
  방붕(뱅드림 갤러리 이용자)이 추천하는 맛집을 지도+리스트 연동 UI로
  제공한다. 지역·종류 이중 필터, 지도 마커↔리스트 항목 양방향 하이라이트,
  구글/네이버/카카오 지도 바로가기 버튼을 지원한다.
  배포: GitHub Pages. 산출물은 index.html 단일 파일.

1. 저장소 구성
  data.csv     입력 데이터(단일 소스). UTF-8-SIG(BOM) 허용.
  main.py      빌드 스크립트(CSV → index.html). CSV를 JSON으로 인라인 주입.
  index.html   빌드 산출물(정적). Leaflet(unpkg CDN)으로 지도 렌더.
  nav.js       공통 상단 네비게이션 바.
  main.bat     실행 배치.
  git_auto.sh  빌드→커밋→pull→push→Pages 배포 대기→브라우저 오픈.

2. 입력 스키마 (data.csv)
    구역        지역 라벨(예: 서울/대전/부산/홍대/서면...)
    이름        상호명
    구글맵링크  구글 지도 URL(있으면 우선 사용, 없으면 검색 URL 생성)
    좌표        "위도, 경도" 문자열(따옴표 포함 가능)
    비고        설명 텍스트
    분류        카테고리(예: 양식/카페·디저트 ...)
  좌표 파싱: 쌍따옴표 제거→',' 분리→float 2개. 실패 시 lat/lng=None(마커 생략).
  구역 정규화: '홍대'→'서울_홍대', '서면'→'부산_서면' (표시 시 '_'는 공백 치환).

3. 처리 파이프라인 (main.py: generate_html)
  3.1 csv.DictReader(encoding='utf-8-sig')로 로드.
  3.2 각 행 → {area,name,google_map,lat,lng,note,cat} 딕셔너리.
  3.3 json.dumps(data, ensure_ascii=False)를 HTML 템플릿에 f-string 인라인 주입.

4. 프런트엔드 동작 (index.html 내 인라인 JS + Leaflet)
  - 지도: OpenStreetMap 타일(opacity 0.7), 초기 뷰 [36.5,127.5] z7,
    zoom 컨트롤 bottomright.
  - 필터: 지역(currentArea) + 종류(currentCat), AND 조건.
      getFilteredData()로 교집합 산출. 'ALL'은 전체.
      지역 버튼 활성색 주황, 종류 버튼 활성색 파랑으로 축 구분.
  - renderList(): 필터 결과를 카드 리스트로. 각 항목 클릭 시
      highlightItem + map.flyTo(z16) + 해당 마커 팝업 오픈.
      모바일에선 지도 영역으로 스크롤 이동.
  - renderMarkers(): 유효 좌표만 마커 생성, bindTooltip(상호명)+bindPopup.
      마커 클릭 시 리스트 항목으로 scrollIntoView + 하이라이트.
      필터 결과 전체를 fitBounds(maxZoom 17)로 자동 맞춤.
  - 지도 바로가기 버튼(getButtonsHtml): 구글은 링크 있으면 그대로,
      없으면 검색 API URL 생성. 네이버/카카오는 "구역 이름" 쿼리로 검색 URL.
  - 반응형: <=768px에서 지도 상단 40vh + 사이드바 하단(자체 스크롤),
      100dvh로 모바일 하단바 높이 보정.

5. 빌드/배포 절차
  main.bat 또는 python -m main → index.html 재생성 →
  git_auto.sh(빌드 포함) → add→commit→pull(--no-rebase --no-edit)→push →
  gh deployments API로 github-pages 환경 배포 성공 폴링(MAX 300s) →
  성공 시 브라우저 자동 오픈.

6. 설계 결정/제약
  - 정적 사이트: 좌표 없는 항목도 리스트에는 노출(마커만 생략).
  - 지도 라이브러리는 Leaflet + OSM(무키·무료). API 키 불필요.
  - 데이터 인덱스는 원본 data 배열 기준(indexOf)으로 항목-마커 매핑
    → 필터링 후에도 안정적 하이라이트.
  - CSV는 BOM(utf-8-sig)까지 허용(엑셀 저장 호환).
